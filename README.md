# Employee Management System

A desktop application built with C# and Windows Forms (.NET Framework) to manage employee records efficiently.

## Features
- **Add Employees:** Register new employee details into the system.
- **Update Information:** Edit and update existing employee records (`frmUpdateEmployee`).
- **View & Manage:** Browse and organize employee data easily.

## Technologies Used
- **Language:** C#
- **Framework:** .NET Framework (Windows Forms)
- **IDE:** Visual Studio
